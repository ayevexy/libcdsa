# Contributing to libcdsa

Thanks for your interest in this project.

## Contribution Policy

This project is currently **maintained by a single author**, and **pull requests are not accepted**.

The codebase follows specific design decisions and experimental ideas that are not open to external modification at this time.

---

## How You Can Contribute

Even without code contributions, you can still help:

### Reporting Issues
- Use GitHub Issues to report bugs
- Provide clear steps to reproduce
- Include relevant code snippets or logs
- Specify expected vs actual behavior

---

### Feature Requests
- Open an issue describing the idea
- Explain the use case clearly
- Be aware that not all suggestions will be accepted

---

### Discussions
- Use GitHub Discussions for questions or general ideas
- Keep conversations respectful and constructive

---

## Before Opening an Issue

- Check if the issue already exists
- Make sure you're using the latest version
- Keep reports focused and minimal

---

## Code Style / Design Notes

The library:
- Is experimental
- Uses non-traditional and sometimes unconventional patterns
- Prioritizes specific design goals over general expectations

Suggestions that conflict with these principles are unlikely to be accepted.

---

## Code of Conduct

This project follows a Code of Conduct based on the Contributor Covenant.

By participating, you agree to maintain a respectful and constructive environment.

---

## Final Notes

Maintainer decisions are final.

If you need something different, feel free to fork the project and adapt it to your needs.
