# Security Policy

## Reporting Issues

If you find a security problem, you can:

* Open an issue (for non-sensitive bugs), or
* Report it privately if you think it shouldn't be public yet

GitHub Security Advisories are preferred for private reports.

## What to Expect

This is a solo-maintained project. There are no guarantees on response time, but I’ll take a look when I can and fix real issues if they matter.

## Scope

Everything in this repository.

## Notes

* This project is experimental
* No pull requests are accepted
* Use issues/discussions for everything else
